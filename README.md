# 🎥 AI YouTube Video Analyzer

AI YouTube Video Analyzer is a Streamlit-based application that analyzes YouTube videos using AI.

The application extracts the video transcript and generates a structured analysis including video overview, important topics, key learning points, timestamps, practical demonstrations, and a final summary.

---

## 🚀 Features

- Analyze YouTube videos using a URL
- Extract video transcript/captions
- Generate AI-powered summaries
- Identify main topics
- Generate important timestamps when available
- Extract key learning points
- Highlight practical demonstrations
- Generate final video summary
- Interactive Streamlit user interface
- Powered by Groq LLM
- Built using Agno AI Agent framework

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Agno
- Groq API
- YouTube Transcript API
- Python Dotenv
